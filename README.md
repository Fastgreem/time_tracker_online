# Онлайн-Табель учета рабочего времени (FastAPI)

Веб-приложение для удаленного отслеживания рабочих смен сотрудников с системой авторизации и автоматической отправкой сводных отчетов на Email бухгалтерии. Полностью исключает необходимость установки стороннего ПО на рабочие компьютеры.

## Особенности онлайн-версии
- **Доступ через браузер**: Работает на ПК и смартфонах без установки файлов.
- **Безопасная авторизация**: Каждый сотрудник имеет свой личный кабинет, защищенный паролем (пароли хранятся в БД в виде SHA-256 хешей).
- **Изоляция данных**: Сотрудники видят в личном кабинете строго свою историю смен.
- **Интеграция с Email**: Автоматическая генерация единого плоского отчета за месяц в Excel и отправка вложения бухгалтеру по протоколу SMTP.
- **Защита конфигурации**: Пароли от почты вынесены в защищенные переменные окружения (`.env`).

## Как запустить локально
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройте параметры почты в файле `.env`.
3. Запустите веб-сервер:
   ```bash
   uvicorn src.main:app --reload
   ```
